# Si (Muse) Miao - Data Science Portfolio

Welcome to my portfolio. This repository contains a collection of my independent analysis and academic projects, showcasing my work in predictive modeling, computer vision, and data visualization.

## 📂 Projects

### 1. [California Real Estate Price Prediction (Regression)](./california-real-estate-prediction)
* **Context:** Professional Experience (Internship at IDX Exchange)
* **Objective:** Developed an Automated Valuation Model (AVM) to predict single-family residence prices using 10 months of proprietary transaction data (170k+ records).
* **Impact:** Achieved a Median Absolute Percentage Error (**MdAPE**) of **7.7%**, reducing the error rate by **67%** compared to the baseline.
* **Key Techniques:** LightGBM, Outlier Detection (IQR), Grid Search CV.
* **Tools:** Python, Pandas, Scikit-Learn, LightGBM.

### 2. [Pneumonia Detection from Chest X-Rays (Deep Learning)](./pneumonia-detection-cnn)
* **Context:** Academic Project (Coursework - STAT 362 Advanced Machine Learning)
* **Objective:** Built a Convolutional Neural Network (CNN) pipeline to classify chest X-rays into three clinical categories (Normal, Pneumonia, Other) to assist in medical triage.
* **Performance:** Achieved **88.5% Binary Accuracy** (Healthy vs. Sick) using Transfer Learning (DenseNet121) and intense geometric data augmentation.
* **Key Techniques:** Transfer Learning, Class Weighting, Data Augmentation, PyTorch.
* **Tools:** Python, PyTorch, DenseNet121, Matplotlib.

### 3. [LegalAid Call Flow Visualization](./legalaid-dashboard)
* **Context:** Academic Project (Coursework - STAT 390 Data Science Project)
* **Objective:** Designed an interactive Power BI dashboard to visualize call center data for LegalAid, an organization providing legal services for low-income residents. Implemented drill-down features to identify bottlenecks in client service.
* **Key Techniques:** Hierarchical Drill-downs, Sequential Data Mapping, Call Lifecycle Analysis.
* **Tools:** Microsoft Power BI, Data Modeling (DAX), ETL (Python/Pandas).

### 4. [Customer Retention & Cohort Analysis](./customer-retention-analysis)
* **Context:** Independent Project (KPMG Dataset)
* **Objective:** Analyzed bicycle transaction data to identify churn drivers and high-value customer segments.
* **Key Techniques:** RFM Segmentation, Cohort Analysis, Data Visualization.
* **Tools:** Python, Pandas, Matplotlib.
